# 编辑器输入与快捷键

2026-10-30核对：集中快捷键、选择／工具门控已完成代表性人工与自动回归，P2按约定Windows范围收尾，见[最终验收](P2_FINAL_ACCEPTANCE.md)。以下描述当前输入契约，逐轮反馈保留原身份，不推广为全部键盘／IME或平台验证。

## 单一维护入口

产品定义的按键绑定、场景、说明及多选／等比缩放修饰键策略集中在 `desktop/ui/src/shortcuts.rs`。`DEFAULT_SHORTCUTS` 同时驱动路由和设置窗口中的“快捷键（当前默认）”；`MODIFIER_HINTS` 管理鼠标修饰键说明。新增绑定须在该处定义，并补充上下文／冲突测试。当前提供固定默认映射，尚无用户改键、配置持久化或全局系统热键。

| 场景 | 默认输入 | 动作 |
| --- | --- | --- |
| 编辑 | Delete | 删除所选图层／视觉组件；不删除素材库原始字节 |
| 编辑 | Ctrl／Command + Z | 项目撤销 |
| 编辑 | Ctrl／Command + Shift + Z，或 Ctrl／Command + Y | 沿历史记忆路径重做 |
| 编辑 | Esc，包括按住 Shift 等修饰键时 | 活动编辑仅取消当前草稿；空闲时解除画布选择 |
| 交互且画布有键盘焦点 | Z／X | 两个占位游戏输入，经宿主模拟门控接纳 |
| 编辑选择 | Ctrl／Command + 点击 | 追加／移除选项 |
| 编辑变换 | Shift + 拖角点 | 保持原缩放比例 |

文本编辑的删除、撤销、光标移动、复制／粘贴及平台输入法仍由 egui／平台负责，不注册为项目动作。没有为尚未实现的保存、导出等功能绑定空动作，也不改变素材导入是否进入历史的现行规则。

## 动作、时序与隔离

按钮与快捷键共用 `EditorAction` 分发，再调用现有 application Command／历史／草稿入口。Delete 将有效选择的最外层目标规范化后一次事务提交，失败不清空选择，不留下部分修改／节点；同选祖先和后代只删除祖先子树。视觉 Component 的删除沿用已有 RemoveComponent 语义，不暗中删除独立文档、音效或原始素材。

项目操作与游戏输入按编辑／交互上下文分流。游戏键另须画布焦点；文本编辑焦点与普通按钮焦点分别处理，不因图层行获得焦点就阻止 Delete。UI 只输出输入请求，暂停后的实际游戏输入仍由宿主管理。

按键只响应新按下，不响应系统自动重复；同一 GUI 帧至多执行一个编辑／历史快捷动作。路由按 egui 帧号拒绝布局重试中的重复消费，避免一次 Delete 在第二次布局中删除新选项。Esc 在画布松手提交之前处理，取消后的迟到松手不能创建节点；长按 Esc 不会在取消草稿后继续清除共同框。

文本编辑优先；前一帧的文本所有权也保护焦点退出的这一帧，避免输入框内 Esc／Enter 退焦点后按键穿透。IME 预编辑期间及提交／取消所在帧屏蔽产品快捷键，失焦清除组合状态。这些是编辑器输入策略，不是 stable 兼容性规则；真实 Windows 中文输入法仍需人工验收。

## 画布选择与模式切换

当前占位投影可单击鼠标下最上层可见图片图层；按实际图层／文档绘制顺序处理，排除隐藏文档、隐藏子树、零不透明度及画布裁剪外的部分。矩阵包含文档／组件／视图映射，拾取保持鼠标所在的投影目标，不因选择而改变画面坐标。只有来源、版本、草稿、尺寸、视口代次及目标均有效的 Ready 帧才能拾取。

复查补充了“非单位文档映射＋组件旋转后拾取，再直接拖动”的回归：最初可以选对图层，但控制框仍走文档输出空间，测试明确失败。现对 Components／Workspace 中的图层统一使用文档到共同空间的映射来计算框和手势父空间；Document 目标保持独立输出语义。旧失败日志与修正前已检查但未冻结的构建记录均保留，不纳入最终构建证明。

这是图片矩形内的几何拾取，没有逐像素 alpha 掩码；图片内透明像素不会自动穿透到下层。它不定义游戏 GUI 判定区域或稳定版玩法实例的选择规则。当前先单击选择，再拖动操作；未添加框选或未选中对象的按下即拖选。

角点／旋转柄优先处理。已有临时共同框内无修饰键的点击／拖动继续保持共同操作；Ctrl／Command 点击可增减成员。空白单击解除选择，不撤销已提交变换。单击选中组中的图片时选最上层图片，组仍可从面板显式选择后整体拖动。

编辑切换到交互时取消本 UI 所有的活动变换／参数草稿，清空全部画布选择和共同框，保留已提交内容及历史；不取消其他适配器持有的草稿。切回编辑不会恢复旧选择。音效组件选择独立，不纳入图像共同框。

后续人工发现图层／组件面板可在交互期间重新选中，见[选择门控修复](P2_INTERACTION_MODE.md)。入口与几何查询均加工具限制，顶部以“预览场景／操作工具”分行说明；GUI占位场景仍能使用编辑工具。下面58d7e931构建的数字保留其历史适用范围，不代表后续修复构建已完成验收。
