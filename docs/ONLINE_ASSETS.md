# 在线素材库：规划与导入契约

状态：需求／架构预留，尚未实现服务端、联网客户端或UI。本功能不增加本轮P2-A3的联网负载或退出条件；先复用稳定的本地资源／导入闭环，再独立验收在线入口。

## 用户行为

在线素材库与本地素材库独立浏览、搜索和筛选。用户可将远端图片直接添加到指定文档的图层组；操作完成时，该图片必须同时成为项目本地AssetLibrary中的可用素材，并由新图层引用。下载完成后编辑、撤销／重做、历史检出、保存和导出不再依赖远端服务一直在线。先下载到本地素材库、以后再创建图层也应作为独立用例支持。

这里的“本地素材库”沿用项目AssetLibrary，不提前混同为跨项目的个人磁盘库；后者仍另行规划。在线目录项、已下载的不可变字节、项目Asset登记、图层实例和最终导出图片分别建模。音频如接入同一在线来源，继续通过独立音效编辑／绑定用例，不隐式成为图片图层或继承图片变换。

## 身份与模块方向

远端条目以来源提供方、条目ID和版本标识寻址，不以文件名、URL或现有AssetId代替。内容摘要用于校验及字节共享，图层只引用本地AssetId／BlobRef，不持有远端下载URL。远端新版本不会原地覆盖旧原始字节或历史内容，更新必须是新的显式导入／替换操作。

UI和未来AI调用同一application用例。application定义目录查询、准备下载及导入结果的窄端口和结构化请求；infrastructure适配具体HTTP／缓存／字节存储，desktop注入。domain、preview、rendering及audio不引入网络能力；下载worker不能持有可变项目会话。没有现实实现需求前不创建插件市场、服务容器或通用下载工作流。

目录结果、分页／搜索状态、进度、取消令牌和缓存属于临时状态，不进入SkinProject或操作历史。来源地址、认证和访问令牌属于本机设置／凭据存储，不写入项目、skin.ini或Git；分享项目可保留经过整理的公开作者、来源ID、版本、内容摘要及授权说明，不保存带凭据／时效签名的URL。

## 直接添加的原子流程

1. 用户选定目标项目会话、文档／组ID及基础修订；建立可取消的导入请求。查询和下载在Command事务外进行，准入／字节／任务数受限，并校验响应长度、内容摘要（来源提供时）、实际类型和解析资源上限。
2. 原始内容进入受管暂存字节存储。只有完整下载及相应校验通过后，才交付不可变的准备凭据；无法处理的类型给出明确诊断，不伪造可用图层。音频未经编辑的原字节保留原则不变。
3. application重新检查会话、基础修订、目标组和项目写通道。在一个事务中登记／复用本地Asset，再创建指向它的图层，作为一个历史节点提交。只下载用例则仅登记Asset；网络和解码本身不成为可逆命令。
4. 成功后转移原始字节租约；失败、取消、Busy、修订冲突或目标失效时不留下Asset登记、图层或历史节点。实际worker／I/O结束、暂存租约释放后才归还预算；历史可达资源继续固定原始字节。

下载期间发生历史切换、目标组删除或其他项目修改时，旧请求不得悄悄应用到新分支。明确返回冲突／目标失效；重新选定目标或修订后另发请求。取消、下载迟到、重试和重复回执必须核对请求／会话代次，不能借UI刷新复活取消的导入。

相同远端版本和内容可复用已有本地素材；共享字节不等于任意合并不同元数据身份。复用策略要有明确结果，不能覆盖原作者／名称等元数据。用户两次有意投放允许产生两个独立图层；同一请求ID的网络重试／AI重复提交不得重复登记或创建图层。最终以本地内容校验结果为准，不信任同名、相同扩展名或远端声明即等价。

## 验收与实施顺序

先确认本地准备凭据、事务导入、持久化与历史资源租约，再实现一个受限提供方适配及独立在线面板；服务提供方、认证协议和后端部署方式尚未定。网络不可用时已导入素材仍可编辑／保存／导出；未完成下载明确显示状态和失败原因。

核心用受控fake／门闩验收：成功同时登记并创建层、相同字节复用、主动重复投放与重复请求区分、缺失／不支持／超限响应拒绝、下载失败／取消／迟到、下载期间修订／历史／组变化、Busy、原子回滚、撤销分叉及跨分支原始字节固定。基础测试不连接真实服务；网络／磁盘故障与提供方协议另作适配器测试，真实在线服务结果不替代核心测试。

新增项目元数据或持久化结构时再明确schema版本及迁移，未知元数据按既有保留规则处理。本轮只记录契约，没有提前修改领域模型或宣称在线导入已经可用。
