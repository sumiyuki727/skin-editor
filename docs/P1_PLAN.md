# P1 无窗口核心实施计划

2026-10-20，计划 v1。**P1-0 工程门槛及 P1-1 模型与不变量已在 Windows 完成检查，P1-2 及后续未实施。** 准入依据为 [P0 收口评审](p0/P0_EXIT_REVIEW.md)，实际检查、源码与平台限制见 [P1 进度](P1_PROGRESS.md)。

## 准入与范围

P0 已选择 Rust 1.95.0／2024 edition、首轮 osu!standard 路线及独立兼容实现；标准负载和资源预算已写明。Windows x64 先开发，Linux 实测延期，macOS 待设备。P1 核心不能导入 UI、GPU、文件系统、网络、音频／图像解码器或旧 P0 实验；平台实现以后经 application 端口接入。

只建立实际需要的 `domain` 与 `application` 包。公开值契约先放 application，不预建空的插件、服务容器、UI、AI 传输、数据库或通用引擎。新建／受验证加载是生命周期用例，项目创建后的内容修改统一经 Command。

P1 包含资源登记与不可变 BlobRef、文档与嵌套组、跨元素组件树及显式坐标映射、变换／可见性／透明度、输出映射、保留未知数据的配置模型，以及命令、原子事务、会话历史、只读查询和可取消草稿。组件先验证几何与输出边界，不套用不可跨输出表达的组效果。测试用内存字节端口，不读图片或真实皮肤。skin.ini 字节解析／保存、PNG 解码、像素合成、桌面面板和游玩均由后续阶段接入。

## 契约与实现约束

- 外部 DTO 带版本（首版 v1），Command／查询／历史控制分别表达；不暴露任意字段写入、UI 控件、闭包或可变指针。serde 仅在确有值序列化需要的契约边界引入并锁定，不因 GUI 实验使用它而让核心依赖整套实验。
- 内部对象身份不是文件名或历史辅助坐标。对象 ID 与已解析命令在提交时稳定生成，重放不再读外部文件或产生新 ID。
- 初期可用简单容器和隔离候选状态实现原子性，历史保存元数据变更与资源引用；不为节点复制原图，不预先引入持久化集合／事件框架。实际性能不满足时再按基线优化。
- 配置未知节／键／原值及顺序信息须可表达。P1 不硬编码未经验证的 stable 默认值、查找顺序、AR／判定或游戏几何。
- 原始字节与可重建缓存分开；测试内存端口也要验证历史可达性和失败资源暂存，不把“当前层没引用”当作可以删除原始数据。
- 核心默认禁止 unsafe；原生调用以后隔离到平台适配包。UI／AI 只依赖 application 公开入口，P1 测试无需设备、网络、个人目录或窗口。
- [组件](COMPONENT_MODEL.md)与[历史地址](HISTORY_ADDRESSING.md)在 P1 按具体不变量落地；[预览控制／呈现](PRESENTATION_CONTRACT.md)与[时间轴](PREVIEW_TRANSPORT.md)仅保留边界。本轮不加入空预览端口实现、GPU 包或评分公式。

## P1 完成条件

R01–R05、R11、R20 的核心／契约范围，以及 R19 的模型范围通过；Command 成功／校验失败／原子回滚／历史往返，历史分叉／资源引用，草稿取消／单次提交均有可重复用例。增加固定种子的随机命令序列或属性测试，持续检查树、引用、失败不变和历史往返不变量。模块依赖检查阻断逆向／循环依赖，并用负向样例检查适配器不能取得项目写入口或可变项目引用；默认无窗口入口可一次完成格式、静态和测试检查。

长历史测试给出可重复的性能与内存基线，失败或取消不留部分项目／节点；实现未突破 [资源原则](p0/RESOURCE_BUDGET.md)。README 此时才新增实际验证的产品依赖、启动与测试入口。代码未完成时不能用 P0 的 245 项检查替代这些结果。

P1 不要求运行真实 stable 或完成 GUI／游玩。进入 P2 前审查公开接口、依赖、基线与已知限制；P2 以实际编辑闭环重测面板／输入、暂停像素刷新和预算。
