# P1 工程与验收记录

2026-10-20。P1-0 已完成 Windows 范围的工程检查；P1-1 及后续尚未实现。本文记录当前事实，阶段计划见 [P1_PLAN.md](P1_PLAN.md)。

## 已交付

- 独立 Rust 1.95.0／2024 edition workspace，仅 domain／application 两个 library 包，application→domain。根锁文件没有第三方依赖，P0 实验不进入产品工作区。
- domain 的非零 ProjectId 值类型；application 的身份会话、版本 v1 的自有查询副本及结构化身份错误。不生成随机 ID，不创建完整皮肤项目或编辑内容。
- 默认单一无窗口入口：`python tools/check_core.py`；可显式指定现有工具链目录。离线依赖、源码、格式、Clippy、测试及 release 库构建在同一入口完成，不自动安装工具或修改全局设置。
- 仓库安全扫描、实际暂存字节检查和本地提交 hook；按用户授权在通过检查的完整增量后创建本地 Commit，不自动推送。
- Windows／Linux CI 配置，固定 checkout 提交、只读权限、不保留凭据；尚未远程运行，不将配置存在计为 CI 或 Linux 通过。

## Windows 验证

| 检查 | 结果与边界 |
| --- | --- |
| 工具测试 | 21 项：9 项仓库、9 项架构、3 项工具链失败路线；无窗口、设备或网络 |
| 核心行为 | 5 项 Rust 单元测试：无效身份、完整宽度 ID、查询版本／身份、独立查询副本；不代替模型／命令／历史测试 |
| 私有访问 | 2 项 Rust 编译拒绝测试，分别阻止外部访问 ProjectId 表示和 ProjectSession 内部状态 |
| 依赖 canary | 独立临时 Cargo 工程实际加入禁止的 UI 包，元数据经同一检查器拒绝；不修改产品清单或锁 |
| 静态与构建 | 格式、Clippy 全目标／feature 且警告视为错误，debug 测试与 release 库构建通过 |
| 来源与隔离 | 当前核心无 UI／GPU／媒体／设备／旧源码依赖，原有 124 份 P0 测量文件保持原字节；新增工具不是旧实验的新成绩 |

本机系统默认 Rust 仍为 1.80.1，验证显式使用已有的独立 1.95.0 二进制目录，Cargo home／输出置于忽略目录。检查器只接受指定版本，缺少已注册工具链时直接失败，不尝试下载；该工具链目录不是产品源码依赖。Windows 链接工具通过已有 MSVC／SDK 发现，仅对子进程配置。

原始运行记录与计量身份写入本地 `artifacts/p1/`；此阶段没有 GUI、真实音频、性能预算或 stable 对照新成绩。245 项旧实验测试没有作为 P1 结果重用。

## 下一步与限制

P1-1 建立完整 SkinProject、不可变资源引用、文档／嵌套图层、仿射变换、无损配置与输出映射的不变量；之后 P1-2 才增加命令／事务，P1-3／4 增加分叉历史及草稿。不能用身份会话冒充已实现编辑器。

新增的玩家资料、统一设置、自动打图、区域描述、外部默认皮肤和全量可皮肤组件覆盖已写入[需求设计](PREVIEW_SETTINGS.md)，尚无这些功能实现。Linux 实测仍延期，macOS 待设备；CI 未远程执行，打包、资源授权清单和低延迟游玩均未验收。
