# P1 工程与验收记录

2026-10-21。P1-0／1／2／3 已完成 Windows 范围的工程、模型、事务与分叉历史检查；P1-4 草稿和完整资源成本基线尚未完成。本文记录当前事实，阶段计划见 [P1_PLAN.md](P1_PLAN.md)。

## 已交付

- 独立 Rust 1.95.0／2024 edition workspace，仅 domain／application 两个 library 包，application→domain。根锁文件没有第三方依赖，P0 实验不进入产品工作区。
- domain 的非零类型化 ID、SkinProject、不可变 Asset／BlobRef、ElementDocument、嵌套 LayerTree／ComponentTree、显式成员映射、仿射／透明度／几何边界、无损配置记录及输出映射。整体构造校验引用、单父无环、成员唯一、数值有效性和输出冲突。
- application 拥有项目，提供 v3 的身份／状态查询、自有快照及统一 submit(CommandRequest)。资源、文档、图层／组、组件、配置和输出经原子 Command 修改，预校验不获得写权限，不提供可变项目引用或任意整体替换。
- 期望节点＋修订冲突、会话隔离及请求回执去重；成功、NoChange、命令／资源失败的已登记请求均返回原结果，差异载荷拒绝。每次有效事务同步发布一个非零 u64 历史节点及可逆元数据补丁。
- P1-3 的 navigate(HistoryRequest) 提供撤销、明确后继重做及任意节点检出，与 submit 共用请求身份／容量。旧节点后继续编辑追加新分支，原子树不删除；切头仅增加活动修订，同头／根撤销／叶重做不增加节点或修订。最近公共祖先的迭代恢复、模型／租约校验全部成功才发布。
- 两类规范地址 n＋base36 最长 14 字符，b 分支坐标最长 28 字符；坐标索引每节点一项，无祖先路径复制。带会话的解析、摘要、子节点／祖先分页（每页 1–256 项）、只读旧快照及关系／租约／回执计数已提供。
- ResourceStore／BlobLease 端口固定已暂存且经适配器校验的原始资源；候选资源获取失败释放临时租约，同内容共享固定，历史引用保留到会话结束。只有内存存储测试，尚无正式文件适配器或实际摘要核对实现。
- 默认单一无窗口入口：`python tools/check_core.py`；可显式指定现有工具链目录。离线依赖、源码、格式、Clippy、测试及 release 库构建在同一入口完成，不自动安装工具或修改全局设置。
- 仓库安全扫描、实际暂存字节检查和本地提交 hook；按用户授权在通过检查的完整增量后创建本地 Commit，不自动推送。
- Windows／Linux CI 配置，固定 checkout 提交、只读权限、不保留凭据；尚未远程运行，不将配置存在计为 CI 或 Linux 通过。

本机系统默认 Rust 仍为 1.80.1，验证显式使用已有的独立 1.95.0 二进制目录，Cargo home／输出置于忽略目录。检查器只接受指定版本，缺少已注册工具链时直接失败，不尝试下载；该工具链目录不是产品源码依赖。Windows 链接工具通过已有 MSVC／SDK 发现，仅对子进程配置。

本轮共 109 个检查用例：81 行为＋6 编译拒绝＋1 可运行示例＋21 工具。原始运行记录与计量身份写入本地 `artifacts/p1/`；此阶段没有 GUI、真实音频、完整性能预算或 stable 对照新成绩。245 项旧实验测试没有作为 P1 结果重用。

P1-1 使用标准库 BTreeMap／BTreeSet 和平坦树，关系与派生矩阵成本按节点线性占用，查询副本当前深拷贝元数据，不复制图片字节。模型的 10000 层用例验证可构造／遍历／克隆／释放；P1-3 另有真实事务／导航的历史规模用例，均不能代替完整资源预算。成员内容变换可查询，但像素合成／输出未实现。配置记录按字节与字段范围保留内容，尚无 skin.ini 解析器；BlobRef 的实际字节摘要核对和文件系统导出校验仍待对应适配器。

P1-2 的[命令契约](COMMANDS.md)明确提交顺序、失败回执、预校验限制、资源固定和容量策略。补丁按改变的资源／文档保存，组件／配置／输出在该类别改变时保存前后值；全局准入身份、去重回执与租约均有会话寿命。默认数量限制不是完整内存预算，文档粒度补丁、请求大小及长历史成本仍需 P1-4 计量。本轮没有加入第三方依赖、运行时线程、网络、GUI 或媒体读取。

application API 在 P1-2 从 1 升为 2、P1-3 升为 3：创建会话仍须提供项目 ID 与不复用的历史会话 ID，新增历史控制／寻址和共享请求命名空间；v1／v2 请求明确拒绝。MODEL_VERSION 仍为 1，尚无项目文件迁移，源调用示例与测试已同步调整，见[迁移说明](COMMANDS.md#接口版本变更)。

## P1-3 规模与资源可达性

以下来自 `crates/application/tests/history.rs` 的真实 submit／navigate／query 调用，非手工构造树；配置内容保持常数规模，不读原图或安装目录。

| 用例 | 断言与观察 |
| --- | --- |
| 10000 层连续编辑 | 10001 节点、10000 边、10001 坐标项、1 分支、深度 10000；每节点两类地址可解析，祖先分页共返回 10001 个唯一节点，旧快照和根／叶／撤销重做往返正确 |
| 10000 同级后继 | 含根和父共 10002 节点、10001 边、10002 坐标项、10000 分支；分页按创建顺序完整枚举，旧地址／首个后继保持可用，隐式重做明确拒绝歧义 |
| 跨分支字节租约 | 两个自制内存资源，替换／删除／分叉后全部保留；存储标为不可用时检出不再 pin，累计仅 2 次固定。会话结束才释放两份租约；对象 ID 不因切头复用 |
| 独立参考模型 | 固定种子 1500 步编辑／撤销／重做／检出，对照独立完整配置快照，核对活动身份／修订、内容、旧查询及节点数量 |

完整无窗口检查中的 13 项历史集成测试总耗时约 0.38 秒；另一次串行仅运行两个规模用例约 0.73 秒（本机 debug 测试 harness，包含构造与断言）。这些不是单次操作延迟、跨机器基准或完整内存测量。关系与坐标项按 N／E 计量，每节点不存地址字符串；补丁、候选克隆、请求回执、租约及大项目实际成本留在 P1-4。原始记录为忽略目录中的 `p1-3-checks.log`／`p1-3-scale.log`；测试不会调用系统时钟、窗口或平台设备。

## 下一步与限制

下一步 P1-4 接入 application 管理的草稿、取消／一次提交、修订冲突／Busy，以及补丁／回执／资源的规模与成本基线。所有内容写入已同步记录历史，后续控制也不得原地改旧节点或绕过资源／修订规则。当前没有正式桌面编辑器。

新增的玩家资料、统一设置、自动打图、区域描述、外部默认皮肤、实际 stable／Songs 来源与必要媒体读取及全量可皮肤组件覆盖已写入[需求设计](PREVIEW_SETTINGS.md)，尚无这些设置／读取功能实现。本轮没有读取真实谱面或安装目录。Linux 实测仍延期，macOS 待设备；CI 未远程执行，打包、资源授权清单和低延迟游玩均未验收。
