# P1 工程与验收记录

2026-10-21。P1-0 至 P1-4 已完成 Windows 无窗口范围：工程、模型、事务、分叉历史、可取消草稿与核心元数据成本基线。正式 UI／GPU／字节存储与完整产品预算尚未完成。本文记录当前事实，阶段计划见 [P1_PLAN.md](P1_PLAN.md)。

## 已交付

- 独立 Rust 1.95.0／2024 edition workspace，仅 domain／application 两个 library 包，application→domain。根锁文件没有第三方依赖，P0 实验不进入产品工作区。
- domain 的非零类型化 ID、SkinProject、不可变 Asset／BlobRef、ElementDocument、嵌套 LayerTree／ComponentTree、显式成员映射、仿射／透明度／几何边界、无损配置记录及输出映射。整体构造校验引用、单父无环、成员唯一、数值有效性和输出冲突。
- application 拥有项目，提供 v4 的身份／状态查询、自有快照、submit(CommandRequest) 及可取消 edit_draft(DraftRequest)。普通批次和草稿 Commit 共用私有发布路径；预校验不获得写权限，不提供可变项目引用或任意整体替换。
- 期望节点＋修订冲突、会话隔离及请求回执去重；成功、NoChange、命令／资源失败的已登记请求均返回原结果，差异载荷拒绝。每次有效事务同步发布一个非零 u64 历史节点及可逆元数据补丁。
- P1-3 的 navigate(HistoryRequest) 提供撤销、明确后继重做及任意节点检出，与 submit 共用请求身份／容量。旧节点后继续编辑追加新分支，原子树不删除；切头仅增加活动修订，同头／根撤销／叶重做不增加节点或修订。最近公共祖先的迭代恢复、模型／租约校验全部成功才发布。
- 两类规范地址 n＋base36 最长 14 字符，b 分支坐标最长 28 字符；坐标索引每节点一项，无祖先路径复制。带会话的解析、摘要、子节点／祖先分页（每页 1–256 项）、只读旧快照及关系／租约／回执计数已提供。
- ResourceStore／BlobLease 端口固定已暂存且经适配器校验的原始资源；候选资源获取失败释放临时租约，同内容共享固定，历史引用保留到会话结束。只有内存存储测试，尚无正式文件适配器或实际摘要核对实现。
- P1-4 的 Begin／Replace／Commit／Cancel、基础＋草稿修订、Busy 隔离及共享请求去重；失败更新保留上一候选，临时资源租约随替换／取消释放，提交后转入历史保留。回执接近上限时保留有效取消位置，300 次更新只生成一个内容节点。
- 根据实际成本将图层／组件树改为私有 Arc 共享不可变存储，历史恢复先组装私有定义、最终整体校验一次；每条新基础 Command 仍单独校验。独立工具测量 minimal／standard／pressure 的两轮 release 成本，产品仍不依赖工具／计时／OS API。
- 默认单一无窗口入口：`python tools/check_core.py`；可显式指定现有工具链目录。离线依赖、源码、格式、Clippy、测试及 release 库构建在同一入口完成，不自动安装工具或修改全局设置。
- 仓库安全扫描、实际暂存字节检查和本地提交 hook；按用户授权在通过检查的完整增量后创建本地 Commit，不自动推送。
- Windows／Linux CI 配置，固定 checkout 提交、只读权限、不保留凭据；尚未远程运行，不将配置存在计为 CI 或 Linux 通过。

本机系统默认 Rust 仍为 1.80.1，验证显式使用已有的独立 1.95.0 二进制目录，Cargo home／输出置于忽略目录。检查器只接受指定版本，缺少已注册工具链时直接失败，不尝试下载；该工具链目录不是产品源码依赖。Windows 链接工具通过已有 MSVC／SDK 发现，仅对子进程配置。

本轮共 131 个默认检查用例：98 行为＋6 编译拒绝＋1 可运行示例＋26 工具。另有 before／after 各三种负载、每种两轮的独立成本验证，格式／Clippy／release 构建通过。原始记录在本地 `artifacts/p1/`，可追溯阶段数值与源码身份见 [机器记录](P1_CORE_COSTS.json)；此阶段没有 GUI、真实音频、完整产品预算或 stable 对照新成绩。245 项旧实验测试没有作为 P1 结果重用。

P1-1 使用标准库 BTreeMap／BTreeSet 和平坦树，关系与派生矩阵成本按节点线性占用；P1-4 改为图层／组件树的不可变存储共享，其他元数据仍复制，不复制图片字节。模型的 10000 层用例验证可构造／遍历／克隆／释放；历史规模与 release 成本单独测量，均不能代替完整产品预算。成员内容变换可查询，但像素合成／输出未实现。配置记录按字节与字段范围保留内容，尚无 skin.ini 解析器；实际字节摘要核对和文件系统导出校验仍待对应适配器。

P1-2 的[命令契约](COMMANDS.md)明确提交顺序、失败回执、预校验限制、资源固定和容量策略。补丁按改变的资源／文档保存，组件／配置／输出在该类别改变时保存前后值；全局准入身份、去重回执与租约均有会话寿命。默认数量限制不是完整内存预算，文档粒度补丁和回执在实际负载下仍可能较大，见成本记录。本轮未给产品核心加入第三方依赖、运行时线程、网络、GUI 或媒体读取。

application API 在 P1-2 从 1 升为 2、P1-3 升为 3、P1-4 升为 4：创建参数仍是项目／历史会话 ID，当前增加草稿与 Busy 并扩展共享请求命名空间；v1–v3 请求明确拒绝。MODEL_VERSION 仍为 1，存储共享不改变逻辑模型，没有项目文件迁移，见[迁移说明](COMMANDS.md#接口版本变更)。

## P1-3 规模与资源可达性

以下来自 `crates/application/tests/history.rs` 的真实 submit／navigate／query 调用，非手工构造树；配置内容保持常数规模，不读原图或安装目录。

| 用例 | 断言与观察 |
| --- | --- |
| 10000 层连续编辑 | 10001 节点、10000 边、10001 坐标项、1 分支、深度 10000；每节点两类地址可解析，祖先分页共返回 10001 个唯一节点，旧快照和根／叶／撤销重做往返正确 |
| 10000 同级后继 | 含根和父共 10002 节点、10001 边、10002 坐标项、10000 分支；分页按创建顺序完整枚举，旧地址／首个后继保持可用，隐式重做明确拒绝歧义 |
| 跨分支字节租约 | 两个自制内存资源，替换／删除／分叉后全部保留；存储标为不可用时检出不再 pin，累计仅 2 次固定。会话结束才释放两份租约；对象 ID 不因切头复用 |
| 独立参考模型 | 固定种子 1500 步编辑／撤销／重做／检出，对照独立完整配置快照，核对活动身份／修订、内容、旧查询及节点数量 |

P1-3 当时 13 项历史集成测试总耗时约 0.38 秒，串行两个规模用例约 0.73 秒（本机 debug harness，包含构造／断言）；这些旧计时不回填为 P1-4 成绩，也不是单次操作延迟或内存测量。关系与坐标项按 N／E 计量，每节点不存地址字符串。原始记录为忽略目录中的 `p1-3-checks.log`／`p1-3-scale.log`；核心测试不调用系统时钟、窗口或平台设备。

## P1-4 草稿与成本验收

[草稿契约](DRAFTS.md)已落实 Cancel／失败／NoChange 不修改活动项目或历史、300 次替换一次提交、Busy 不阻塞读查询、冲突与跨接口去重，以及临时字节租约的取消／转正。内部故障用例验证失败发布后仍可恢复或取消；取消不因回执容量锁死。

[核心成本基线](CORE_COST_BASELINE.md)对两个构建各做三种负载、每种两个独立 release 进程。每进程真实提交 10000 小事务，保留 A／B 分支、完整往返一次，随后 300 次草稿替换并取消；断言内容、节点与资源数量。标准为 100 资源／10 文档／500 层，压力为 1000／100／5000 层，均只含元数据，不读图像。

| 指标 | before | after（当前实现） |
| --- | --- | --- |
| 标准私有提交采样峰值 | 约 576.6 MiB | 293.62–293.90 MiB |
| 标准 10000 事务 wall／CPU | 3.798–3.828／约 3.813 s | 2.280–2.281／2.281–2.297 s |
| 标准分支往返 wall | 约 2346–2347 ms | 4.61–4.77 ms |
| 压力私有提交采样峰值 | 594.18–597.61 MiB | 298.88–299.18 MiB |
| 压力 10000 事务 wall／CPU | 74.812–79.389／74.766–79.094 s | 29.656–30.128／29.625–30.047 s |
| 压力分支往返 wall | 41043–43511 ms | 13.96–14.42 ms |

before 的高成本没有隐藏：先保留源码／可执行快照及原始报告，再采用私有不可变树共享与目的状态一次校验；旧分支、字节保留和命令校验语义均未删减。当前约 294 MiB 的长历史仍是实际成本，真实字节／GPU／UI 加入后的完整预算必须重测；其他文档分布、更多草稿及巨大载荷未覆盖。

## 下一步与限制

下一步可进入 P2 最小桌面编辑闭环：组装现有核心、呈现／GPU 生命周期桥、素材库与图层操作、草稿／Esc 绑定及占位场景暂停刷新，并按实际组件复测完整预算。所有内容写入仍走统一 owner，不能原地改旧节点或绕过资源／修订规则。当前没有正式桌面编辑器，本轮没有提前实现 P2。

新增的玩家资料、统一设置、自动打图、区域描述、外部默认皮肤、实际 stable／Songs 来源与必要媒体读取及全量可皮肤组件覆盖已写入[需求设计](PREVIEW_SETTINGS.md)，尚无这些设置／读取功能实现。本轮没有读取真实谱面或安装目录。Linux 实测仍延期，macOS 待设备；CI 未远程执行，打包、资源授权清单和低延迟游玩均未验收。
