# 历史导航补充与 P2-A3 无 UAC 细分

2026-10-26。六类历史系统标签的[契约](HISTORY_PRESENTATION.md)已补齐，普通Undo／Redo的分叉路径记忆已实现；保存回执及标签UI仍未实现。P2-A3新增完整Painter、缓冲上传、纹理上传、绘制编码区段及互斥墙钟分区，两轮普通权限原生检查通过。按用户本轮要求，**没有请求UAC、没有构建／启动独立CPU采集器，CPU验收未执行，P2-A3未验收。** [结构化证明](P2_HISTORY_PAINTER_PROOF.json)保留结果与51份旧证明身份。

## 历史行为与版本

application API v6在成功Undo进入分叉父节点时保存该父节点到刚撤销的直接子节点的选择；隐式Redo据此返回原分支。单子节点不需额外记忆，多层撤销／重做可恢复每一处分叉路线。成功显式检出其他节点清除普通导航记忆，同头NoChange、冲突、Busy、恢复失败和回执重放不覆盖它；无记忆的多后继仍明确返回歧义。节点、补丁、坐标及旧分支资源不删除或改写。

新增回归验证原分支并非最新子节点时仍可正确返回、改变后的最近Undo路线、无效／失败／Busy／缓存结果、旧API v5拒绝。10000层线性历史完整Undo／Redo后，额外分叉偏好条目始终为0；统计返回的是条目数，不冒充整个历史的分配器字节或成本基线。原有深历史／同级分支／跨分支资源及随机参考模型回归保持通过。项目领域模型仍为版本2，当前没有磁盘格式迁移或历史持久化。

六类标签为保存、曾保存标记、分支、当前、末端和起始。末端是叶节点，起始是根；新建单节点同时带有起始／末端／当前标签。拓扑和当前头可由现有只读查询推导；正式六类标签UI及真实保存回执需后续接入，不提供任意标记成功保存的项目写入口。折叠不删除节点、不改变普通Undo逐个节点的粒度，保存类状态独立于SkinProject和Git。

## Painter 格式2与无 UAC 路径

继续使用原默认关闭的framework-trace及官方profiling后端，无新依赖、框架分支、GPU提交或声音供给策略。诊断格式2新增整个Painter、Renderer::update_buffers、update_texture及render的包围区段；格式1读取仍支持原类别，不把原格式缺少的区段报告为0成本。互斥分区先验证每个子区段被所属Painter完整包含且彼此无重叠，再计算明确的时间间隔；禁止直接相减不同样本的中位数或把剩余归为驱动。

`--no-uac`分支在创建采集器之前转入固定两轮普通权限检查；该路径不构建采集器、不调用runas、不请求提升。回归用禁用Collector／构建函数的mock验证该路径。保留原始进程计数，但cpu_meter_validated为false、cpu_budget_passed为null，不能用低分辨率计数或墙钟估算追认单核≤15%通过。

普通发布SHA为`25abaf3264995669169dc1b4b961926164d2b045f6a6dc4f729c5cd00214d31d`，诊断发布SHA为`8703b22d2ab30069f2f46b2e992681376deb54cdd41c543bbebf5576c5489468`，两种构建各连续两次一致。普通入口没有自动安装观察器。原生阶段运行时源码、测试摘要及两份二进制保持固定；性能记录没有混入编译或测试负载。
