## 决策、检查及限制

证据不支持继续把主要差距寄托在Painter未单列的锁／建立／释放间隔：它只有约0.12–0.14个百分点。下一增量先界定约1.91–2.02个百分点的scope外main，并为应用UI／框架约5.25–5.55个百分点选择可验证的减重复工作候选；不能直接断言scope外都是winit、驱动或可消除成本。驱动起始线程作为独立后端对照目标保留；当前不改变后端默认值、不叠加网格／暂存缓存或声音策略。

四轮各64个场景／64个试听事件，提交观察p95最高12.7672 ms、单次最高13.6962 ms，原20 ms判据通过，仍非设备消费或声学延迟。暂停恢复、定位、热替换、草稿取消、历史切换、双通道及第33 Voice拒绝通过。PCM峰值2435072→0字节、背景读取8192→0；回调受管释放0、端点回调内交还0／范围外交还1、最多2个GPU目标。采样工作集最高153.922 MiB、私有提交241.973 MiB，原512 MiB进程内存门槛通过。

新增7项确定性回归覆盖互斥嵌套、裁断、等待不算CPU、错误身份、保守重叠、结构／父级错误、零时长及捕获准入。`check_core.py`通过268项Python＋134项核心Rust、格式、Clippy及依赖边界；测试写法简化后单独复跑7项通过。产品Rust与依赖未变，沿用上一轮同构建360项默认／366项feature桌面测试及逐字节像素回读证据，本轮没有新的桌面构建或GPU像素成绩。
