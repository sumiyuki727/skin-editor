# P2 C3：完整资源循环与关闭基线

2026-10-27，按用户要求继续收尾P2，P3暂缓。本轮使用当前分离声音／持续背景、真实PNG及完整Editor UI。旧P0循环和C2单次关闭保留自身范围，不能直接关闭C3。

## 已确认的所有权修复

新增回归先确认：缓存Images销毁后，外部仍持有像素时RGBA预算从16 KiB提前退到0。旧CachedRaster持有预算租约，而Raster.pixels可独立克隆逃出缓存寿命。预修复失败日志保留在`artifacts/p2/resource-cycles/rgba-before.log`。

现在RasterPixels共同持有不可变字节和不透明驻留租约；克隆共享同一分配，最后像素引用释放后才退还。不能提取无租约的内部Arc。渲染只读字节／采样与合成语义不变，没有逆向依赖、核心接口／项目格式变更或新依赖；桌面内部Rust调用方由Arc字节改为该值包装。ByteObservation只持有计量元数据，既不固定缓存／字节，也不允许重置额度。测试覆盖缓存销毁后借用、多个像素别名、共享一次计费及最后归还。

图形准备及素材导入的关闭观察在实际join完成后才成功；线程panic不能被记作正常清理。GPU关闭等待错误也保留为失败。准备取消、结果归还与回调／GPU租约结束分开核对，不把清空请求当作实际释放。

## 预先固定的执行计划

完整检查和默认feature／release／offline／locked两次相同构建后，先运行同构建自有GPU回读及两轮短smoke，仅确认接线；通过后执行一个固定20轮进程。不做静默重试、截取后半窗口或设置“允许泄漏”额度。数值超限和未完成情况保留，不能改写旧证明或CPU门槛。

同一窗口、GPU设备和eframe渲染器持续存在；每轮重新创建Editor、SkinProject会话、原始／RGBA存储、NativeHost及其准备线程、导入线程、音频准备／供给／背景读取和原生端点。NativeHost自己的pipeline和资源池也随每轮所有者释放，不把本轮称作整个GPU设备／驱动或进程重启。普通默认声音路线尚未晋升。

每轮加载同一自制100张1024² PNG、10文档／500层、16 WAV资源；独立会话ID，目标文档轮换，使十个文档各打开两次。第1轮创建PNG，后19轮从同一文件集重新登记／解码；360秒自制WAV文件只生成一次，各轮重新打开受限只读句柄和有界背景缓冲。资源登记与修改仍经application，文件不是用户项目打开／持久化功能。

每轮至少播放6秒并满足真实背景推进和原生复制帧数，完成场景／试听各32个请求与16次图层组透明度草稿更新；严格匹配请求ID、完整来源、通道及Voice。图像修改与触发固定错相，超过80 ms诊断护栏或未发布图像被覆盖明确失败。样本按每轮双通道分别计算提交p95≤20 ms，再汇总；不以新计数代替目标Voice。

随后准备长声音，在两通道确认首次原生复制且仍活跃时开始关闭；再提交一次图形请求，确认实际准备尚在途（包括已完成待收结果），立即发起关闭。取消准备并join、停止原生输出取得准确端点、清理导入／图形工作、等待GPU及最后绘制租约、丢弃项目历史。先检查原始／PCM／RGBA、源GPU／目标／暂存归零及任务成功退出，再销毁整个Editor；计量观察不持有资源，销毁后再次检查额度。下一轮只能在本轮实际释放后启动。

每轮关闭后先静置4秒，再采样4秒关闭基线；固定排除前0.5秒，至少保留2.5秒有效跨度。最后再静置10秒、观察65秒，用于延迟释放／私有提交趋势；此处是关闭Editor后的诊断外壳，不冒充C1的完整UI稳定CPU验收。初始外壳基线、20个关闭基线及最终观察分别保留。

阶段ID单调且名称含轮次，采样前后核对当前原生阶段文件：跨阶段／暂不可读样本仍保留到全生命周期内存和已知GPU峰值，仅不进入某个播放／关闭基线。新一轮加载的阶段标记先于资源分配，防止把打开开销混入上一轮关闭曲线。阶段读取有界，不依赖系统窗口捕获、真实客户端或sleep猜测竞争。

## 判据与解释

沿用[预算v2](RESOURCE_BUDGET.md)：全流程零欠载、无故障／协议溢出，双通道请求至首次复制观察p95≤20 ms；工作集与私有提交≤512 MiB，PID GPU dedicated≤256 MiB／shared≤128 MiB，所有已知加载峰值也检查。各播放／关闭窗口GPU未知不能当0。受管上限、回调所有权及真正释放保持，CPU帧p95≤16.7 ms，长帧另列。原始GetProcessTimes只记录，不做独立CPU有效性或15%目标达成声明；不扣除观察成本。

关闭基线列出原始序列、首尾差、前后五轮中位数差、全20／后10／后5斜率与范围，并核对最终65秒是否继续增长。工具把行为／预算和趋势审查分开，不自动宣布C3通过：持续正增长须定位或保持未关闭，不能只因低于512 MiB判定无泄漏。已归还的受管对象、分配器／框架／驱动保留和诊断摘要分别表述；不从总量估算扣减。
