# P2-A3：分离供给候选的原生短轮

2026-10-23。接续[背景储备与复制时钟](P2_BACKGROUND_COORDINATION.md)。本增量为候选接入 CPAL 实际借用的 F32 缓冲，补齐停止交还与声音身份回执；**不改变普通编辑器、AudioSupplyClient、声音默认策略或验收门槛**。它不是 P2-A3 的长时／图形组合验收。

## 执行与资源所有权

`separated_native::PreparedDevice` 只读探测默认设备，当前候选明确限制 Windows、44.1／48 kHz、单／双声道 F32；不支持的格式明确报错。探测、构建、开始和结束分别执行，构建不发声。原默认后端的 I16／其他平台路径不因此取得候选成绩。本轮没有新增依赖或修改锁文件。

CPAL 闭包独占 OutputConsumer，数据回调不访问 Runtime、项目、GUI、解码器或文件。每块最多交给既有合成器 2048 帧，更大的设备缓冲分块处理；实际储备不足仍逐帧累计，不能以静音掩盖。自有数据回调只操作预分配平面、有界 SPSC、固定报告和原子计数，不调用时钟、分配、锁或等待。后端提供的时间戳只复制进诊断值；CPAL／系统引擎内部行为不能由自有代码审查代替。

停止先销毁 OS 流，闭包析构将独占端点移入预建的单槽返回通道；该析构不属于数据 render 函数。控制端始终保持接收端直到流销毁完成，再核对返回并交给 BackgroundOwner.finish，释放背景、暂存和 Runtime 实例。CPAL 0.18.2 的 WASAPI Stream::drop（缓存源码 stream.rs 的 479–496 行）在调用方不处于工作线程时 join；本适配器的流只由控制端持有，不把流句柄传入回调。回执不等同于设备残余已经播放或声学静音。其他后端的析构行为仍未实测。

构建失败也保留返回接收端，play 明确失败，随后仍可 stop／finish；接收端异常遗失不提前退款仍活着的消费端存储，消费端实际销毁后可走既有 abandoned 回收。正常返回、PCM 最后所有权和端点释放均在控制侧完成。没有添加全局服务或第二套素材／候选规则。

## 复制边界与观察

新增门闩回归先复现了选择性取消的窗口：Voice 最终撤销检查之后、调用者输出复制之前暂停测试线程，此时取消原试听仍会复制旧样本。修复将调用者的复制前检查点移至 Voice 最后校验之前，随后才进行有界重算、通道核对和实际复制，正常返回仍位于复制之后。取消该实例不改变背景或无关实例。已进入最后校验／复制事务的块与后端已经持有的副本须区分，不承诺在任意指令中断点撤回整块。

HandoffReport 的 runtime_first 由实际保留的 first 与绑定 Runtime 的声音 ID 组成，在复制后、实例退休前取得。流内使用独立的 128 条 Copy 回执队列，不通过“ID 大于某值”或其他流的计数替代目标实例；溢出明确计数并使诊断失败。队列、实例元数据和分配器开销额外有界，不计入 PCM 样本预算。所有 PCM 沿用共享总 32 MiB／单份 4 MiB，背景 Copy 环及三个暂存平面继续在分配前预留。

短轮每个通道 64 次立即触发。自制短音首样本非零，背景和短音幅度均很低；该回执标识声音开始向实际 CPAL 缓冲贡献样本，不测混音后的可听度或声学起音。本轮“上界”从 Runtime.trigger 调用前计到控制侧收到精确回执，包含接纳、供给、回调与约 2 ms 观察调度，不扣观察余量；回调提供的时间戳／序号／块偏移另存。未用回调入口时间冒充复制完成，也没有由阴性队列读取推导未经保证的下界。一般音频的首描述符复制可能包含开头静音，不能直接沿用此延迟解释。

这里的触发直接在诊断所有者执行，所有者以 2 ms 节奏 pump／补充，与 GUI 帧率独立；**尚未经过 AudioSupplyClient 的有界控制队列或完整 UI 请求入口**。故本轮只验候选原生边界，不能把它与旧默认路径的完整控制请求做因果性能比较，也不能关闭最终 UI 端到端 20 ms 关口。

## 固定计划与验证

无设备新增 10 项 Rust 回归：单／活动闭包交还、遗失接收端、32 个精确实例及第 33 个拒绝、取消后不复制／不回执、非法块、4096 帧请求准确报告 2048 帧不足、128 条观察队列溢出、外来端点拒绝、门闩工作线程退出，以及上述复制前选择性取消。另有 5 项 Python 结果校验，拒绝缺失／重复／非目标探针、欠载、超时、设备异常、错误清理、EOF 冒充连续背景或超预算。

原生脚本 `tools/measure_separated_native.py` 使用同一 release 二进制和固定两进程计划，不因失败自动替换或重试。每轮依次验证冻结空闲、两通道 64 次立即触发、同帧 16＋16 Voice 与第 33 个拒绝、热激活无背景锚点重置、冻结／试听隔离、恢复和定位 100 帧后恢复，最后停止归还。有限背景为同格式的 10 秒自制 PCM；检查定位前后未达 EOF，不能用 EOF 静音取得零欠载成绩。32 Voice 阶段约 2.1 秒；这是短成本观察，不代表持续 32 Voice 长负载。

结果与源码／二进制身份见 [证明](P2_SEPARATED_NATIVE_PROOF.json)，原始记录保留在忽略目录 artifacts/p2/native-separated/。默认完整检查不打开设备；原生脚本只读取自己启动的进程 CPU／内存，不打开 GPU／窗口、读取私人音乐或做系统捕获。

最终格式、Clippy、无窗口和边界检查共 **495 项通过：96 Python＋130 核心 Rust＋269 桌面 Rust**。此前 fixture 调用缺少 GateToken 的编译失败、复制前取消的预期失败及早期检查均保留。自查收紧设备配置为只读入口后，按最终 139 份源码／配置／工具身份重跑全部检查及 release 构建，再顺序完成两轮原生计划；测量时没有并发构建。27 份旧证明保持原字节。

本机 Windows 10 build 19045、默认 48 kHz 双声道 F32、设备报告周期 480 帧；两轮各 64＋64 个精确短音回执和 32 个批量回执完整，无设备错误、合成错误或观察溢出。结果只绑定该环境和构建，Linux／macOS 及不同设备须另验。
