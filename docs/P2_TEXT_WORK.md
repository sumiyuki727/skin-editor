# P2-A3：控件细分、文字复用与图集失效契约

2026-10-26。本轮完成细分观测、字体失效契约回归、两轮文字统计及独立CPU复查。32 Voice阶段约98.36%的文字实例复用上一批已出现的Galley；四轮CPU仍为17.3364%–20.6053%单核，全部超过15%。六轮零欠载，提交观察p95最高12.4283 ms，内存和旧资源清理通过。**只增加诊断和契约，未取得CPU优化收益，P2-A3尚未验收。** [结构化证明](P2_TEXT_WORK_PROOF.json)保存全部结果；46份旧证明不变。

## 复用边界

| 对象 | 当前可用路径 | 后续复用必须满足的条件 |
| --- | --- | --- |
| 文字排版 | 每次通过egui正常文字接口查找，由框架维护Galley缓存 | 不绕过字体定义、字体提供者、字形栅格化器、缺字策略、DPI、字体选项与图集重建的失效路径 |
| Galley行网格 | 使用本次UI处理取得的新鲜Galley，由正常tessellator消费 | 排版对象身份相同仍须重算本次位置、裁剪、颜色、透明度、下划线、角度、层变换和绘制顺序 |
| 跨帧加工网格／GPU缓冲 | 当前未采用 | 需要可靠的Context／图集代次及完整绘制状态契约；图集尺寸、DPI、TextureId或相同文字都不能单独授权复用 |
| 控件交互和布局 | 每次UI pass正常执行 | 不缓存Response、跳过热区、焦点、键盘、IME、拖动／Esc、滚动、无障碍信息或窗口布局；丢弃／重排pass也须正常处理 |
| 项目与音频状态 | 继续从application查询并按既有流程同步 | 来源、草稿、历史、选择、准备和错误不得因绘制复用延迟；声音供给继续独立于GUI |

正常刷新与暂停下刷新沿用同一契约。可复用绘制数据不能成为布局或项目状态的真值；纹理和GPU租约仍由宿主管理，不能将字体纹理ID或排版Arc作为GPU所有权。

锁定egui／epaint 0.37.0源码提供的依据：`Fonts::begin_pass`会因选项变化及图集填充超过阈值而清除排版缓存；`GalleyCache`按LayoutJob与像素比例查找并维护使用代次；Label仍为每次调用处理布局／intrinsic size和交互，tessellator再消费文字行网格。新增回归使用公开API验证：正常连续查找复用同一排版对象；DPI／栅格选项／字体定义变化产生新排版；图集重置并重新填满后，即使完整纹理尺寸相同，旧文字UV也可不同；同一排版Arc对应的位置和颜色仍会变化。

完整／局部字体纹理更新只能作观测，不能代替上述完整失效代次。当前没有为外置长期网格缓存建立可靠代次入口，因此先验证框架已有复用与每帧网格规模，不增加一个依靠尺寸猜测失效的缓存。

## 新观测的范围

UI仍只同步报告阶段枚举，时钟与记录由host持有。场景栏拆成控件、时间／输入读数和外壳；音效面板拆成设备／监听控制、被动状态、素材库、组件列表、参数、准备状态和动作。宿主边界格式4最多32768行；旧格式1–3及各自16384行上限继续读取和回归，不重解释旧证明。所有阶段互斥，父组可回汇，不能将子段与父组重复相加。

`--verify-text-work-gui`显式启用框架现有output hook上的只读统计，普通入口不安装它。它记录相邻输出中Galley弱身份复用数量、缓存驻留数、预备行网格顶点／索引量及字体图集更新；记录不包含文字、输入值或指针地址，不修改FullOutput或调用替代绘制。身份相同不等于完整绘制可复用，驻留数变化不等于缓存命中／未命中次数，预备行网格规模不等于最终GPU顶点数或文字CPU成本。

统计最多1024条输出、每条512个文字实例和32层嵌套，容量溢出明确失败。两个预分配弱引用数组只观察相邻输出，关闭时清空；弱引用不保留Galley内容或字体像素，但可延迟其Arc分配块回收至下一次清理，成本计入宿主。观测行约128 KiB、两个数组约8 KiB；格式4的边界记录约768 KiB，均仅在显式诊断中分配。统计自身墙钟单列，不从CPU扣减。

`tools/measure_text_work.py`固定两轮普通权限原生检查，使用原背景／32 Voice／暂停恢复／定位／热替换／草稿取消／历史脚本，不申请UAC。原CPU读数和谓词保留，CPU计量校验明确未知；墙钟与复用比例不能授权15%通过。独立CPU复查另外沿用严格参考和固定观察关／开／开／关，不将统计墙钟换算或扣减为CPU。
