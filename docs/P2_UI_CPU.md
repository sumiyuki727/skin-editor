参考连续占用99.9209%／99.9811%单核，周期2.5125%–2.6114%，零漏周期，全部原谓词通过。产品会话36.767秒、196份线程生命周期、45份分配buffer；身份、容量、schema、事件及buffer丢失均0，会话正常停止排空。采集回调累计墙钟约0.604秒，只覆盖部分观察成本，不作为CPU扣减。
