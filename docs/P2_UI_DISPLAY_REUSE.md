## 候选范围和取舍

候选只在UI层复用场景时间／输入计数、上次试听来源、有效来源及四条音频规格文本，最多七个固定槽位；只保存标量键及有界格式化字符串。来源比较包含会话、节点、修订、导航和草稿身份／修订／基础状态，旧版本标记独立入键；时间读数保持原三位小数且不节流。准备状态、错误、选择及控制继续即时读取，所有控件仍每帧运行输入、布局和绘制。

检查锁定egui 0.37.0源码后，没有引入跨帧Galley缓存。框架已在`FontsView::layout_job`内缓存排版，`Fonts::begin_pass`会因字体选项或字形图集填充而清除它。当前公开接口没有为外部长期持有的Galley提供完整图集代次契约；此外，直接将Galley传入Label与普通文本的换行／intrinsic size路径不同。仅以DPI、文字和宽度作键不能证明正确。此事实不表示所有网格复用都不可行，后续方案须明确与框架字体／图集生命周期的交接。

候选的四项Rust回归覆盖相同键不再格式化、完整来源变化与旧版本标记立即刷新、一万次变化后的容量／驱逐，以及更换Context、字体大小、DPI和换行宽度后的新鲜布局一致性。既有输入／Esc／草稿／历史及音频同步回归继续执行；本轮没有人工物理输入验收或新的IME专项成绩。

候选通过712项默认检查（236 Python＋130核心Rust＋346桌面Rust），两次release SHA-256一致：`5b02c067b2c70736a67cb63d81523e3a2e2dade968b1c4d07f1771b93f7d957d`。冻结源码、候选同名二进制和检查日志保存在`artifacts/p2/ui-display-reuse/`；整个原生采集期间源码和二进制未变。
