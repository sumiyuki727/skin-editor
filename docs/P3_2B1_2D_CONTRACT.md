## 1. 本片范围

依据[B1-2C欠证](P3_2B1_2C_REVIEW.md#3-明确未补齐的历史原件证据)，只加强实验FileFactsReader的完整观察准入：既有完整文件验证成功后，再逐代精确核对历史原件时序。每代集合取该代全部已提交节点状态的原件并集，包含非当前分支、未使用和后来删除的素材，共享原字节只计一次。不从当前头、当前素材库或最终全局原件集合推定历史集合。

本片不新增公开端口、历史原件摘要或相等字段，不改变B1-2C查询的范围；不宣称完整历史q、NoChange或保存资格。API7／捕获3／协调1、文件／记录格式及既有接口版本不变。旧standalone读取／writer不增加时序资格或新写入能力，不修复旧文件。保持Experimental／Insufficient／BudgetUnproven，不安装A2事实、不解除Unknown、不跨B2。

## 2. 可复用证据与接线

既有full逐一读取／核对全部原始字节、全部节点原记录及完整块图；codec的Record::finish精确核对各块refs／blobs与实际字段。它已验证各代nodes为cache.order追加前缀、originals增量属于全局原件且不重复，以及最终并集。因此新遍历只借用Cache Row.refs／Row.blobs，不再次解码项目、读取原字节、克隆StateBundle或调用blocks::closure。

状态根必须使用原record.state，不能使用重新编码的canonical；后者可能不在原块表。按checkpoint.node_count增加节点范围，累计所有旧分支的已访问块与原件位图。全局最多8项BlobRef仅作为SHA到已验证长度的字典，不能作为历史结果集合。

复用FileFactsReader::validate现有逐代read::checkpoint调用：ParsedCheckpoint只新增只读original_root访问器，在已有legacy_request提取循环同步填固定128项原件索引根数组。不新增checkpoint解析、read_paged、Cache字段或writer变更。随后严格helper接收已验证Cache和对应根数组；任何失败不发布部分观察。

声明侧只沿已验证originals history-index.refs到history-page.blobs累计，要求index.blobs为空、page.refs为空，不能穿入节点状态图。既有full已核对角色、页结构、条目SHA与长度及重复声明；新helper继续检查所用块存在及种类。每一代的累计声明位图必须与真实累计状态闭包完全相等，不仅核对最终并集。

## 3. 固定工作与预留

硬上限沿用单Reader：8192块、64节点、8原件、128提交。借用块索引使用固定8192项Option<&Row>，按已有BTreeMap键顺序填充，以row.block.hash二分查找；不复制块字节。固定u16队列最多8192项，已入队位图1024字节；入队即标记，跨全部状态累计去重，不能等出队才去重。每个块至多一次入队；每个根、边和原件循环检查取消。

新增临时控制租约在inspect调用validate前取得：静态列式覆盖2×Work、2×128根数组、2×8项BlobRef字典及有界辅助标量余量。申请成功后才进入构造工作区的函数；临时工作全部退出后归还，与旧2Data、路径、存活候选／观察共用既定512KiB池。旧2Data持有账本不改，不把临时额永久附在观察上，也不提前归还。

固定容量按size_of给出；不因逻辑length或只看usage不变声称旧全路径无分配。仍欠旧Cache、累计RestoreNode、codec、JSON／Vec／Map、PNG、SQLite和临时盘的共同64MiB证明。A控制512KiB是另一池；本片不证明无限Reader宿主聚合。

原有N／N−1用例须区分长期保管额度与观察临时峰值。若新临时工作使旧用例在inspect先失败，明确更正准入阶段：保留真实候选后再测观察聚合N／N−1，并补独立prepare边界；不能只放大预算、删掉失败断言或把错误阶段叫原路径通过。既有Work／Ack／Drop／旧观察／页断言保持。

## 4. 失败、取消与来源

任何代次提前／迟到声明、缺块／缺原件映射、越界或取消均拒绝整个新观察，保留源字节、旧观察与页、旧候选及实际所有者。新取消探针只在至少处理一条真实状态边或原件引用后触发；节点／边／声明循环也检查令牌。失败清理沿既有路径，临时工作实际退出后才退额，Reader先退出仍不释放存活观察／候选的原有租约。

查询继续核对既有完整来源；B1-2C原件字段仍不存在，缺Commit仍为None，不是NotCommitted。真实q、原Ticket／expected、独立selectedCommit语义及恒Insufficient结论均保持，不从严格读取成功签发PreparedWitness。
