# B1-2V 解析中的文本、待插入键和共享缓冲

Small 一代元数据页中的数组、已拥有的文本（含待插入键）以及当前页的解码字节缓冲，按可同时存活的分配合计，保守上界为 **49 MiB**。未转义的键在等待子值期间可以直接借用原始页。已转义的键在解析子值前取得自己的解码文本。重复键在解析对应的子值之前拒绝。[页解析器](../desktop/infrastructure/src/project_format/json.rs) · [分阶段容量断言](../desktop/infrastructure/src/project_storage/file_facts.rs)

## 文本所有权与释放

从字节切片解码时，serde_json 对未转义字符串交付输入切片，对已转义字符串交付暂存缓冲中的短借用。紧凑读取器将前一种对象键保留为借用，子值成功后才为 Map 复制键。后一种键在短借用结束前复制一次，随后把所有权移入 Map。字符串值在交付给 DOM 时取得自己的缓冲。重复键或子值失败会释放局部所有者。已经插入的键和值与该页一起释放。[锁定版本的切片解码](https://github.com/serde-rs/json/blob/20572a6d066958542d79cdd6cf1a7cd9f0c8e1f8/src/read.rs)

Rust 1.95.0（`59807616`）的 `str::to_owned` 按 UTF-8 切片长度申请容量并复制。真实切片入口上的文本从取得所有权时起即为精确长度。已拥有的键、值和祖先正在等待的键对应互不重叠的输入文本片段。转义后的字节数也受各自片段长度约束，因此单页这些文本的容量总和至多为原始页的字节数。页的原始字节仍由块缓存持有。[字符串复制](https://github.com/rust-lang/rust/blob/59807616e1fa2540724bfbac14d7976d7e4a3860/library/alloc/src/str.rs) · [切片复制](https://github.com/rust-lang/rust/blob/59807616e1fa2540724bfbac14d7976d7e4a3860/library/alloc/src/slice.rs)

## 唯一的解码字节缓冲

此证明适用于 `serde_json 1.0.154` 的 `from_slice`、`std` 和 `float_roundtrip`。一个页解析器只有一个 `Vec<u8>` 暂存区，嵌套对象和数组都复用它。开始下一个相关记号时清空长度，已有容量可能一直保留到输入结束检查。解析成功或出错返回时，解析器释放该缓冲。[依赖锁](../desktop/Cargo.lock) · [锁定版本的解码路径](https://github.com/serde-rs/json/blob/20572a6d066958542d79cdd6cf1a7cd9f0c8e1f8/src/de.rs)

设 B 为 Small 单页原始字节上限 256 KiB。以下均计算 `len + additional` 的最大需求：

- 字符串解码追加已消费的原文区段或转义结果。非 ASCII 转义预留四字节时，已读取至少六个转义字节；代理对已读取十二个字节。无效转义、控制字符和非法 UTF-8 在已读前缀内失败。
- 长数值的整数部分转存已消费的有效数字并继续追加数字。小数溢出路径可能补回前导零，补零后的有效数字只对应已经读取的整数和小数位。后续小数位各追加一次。指数位单独累计，指数溢出沿既有规则报错或下溢。上述需求均至多为 B。数值转换算法自己的工作内存另计。

锁定的 Rust 实现对字节缓冲按原容量两倍、当前需求和最小非零容量 8 中的最大值扩容。实际扩容时旧容量小于需求且需求至多为 B，故新容量至多 **2B（512 KiB）**。即使分配器在扩容时同时保管旧区间和新区间，两者合计也至多 **3B（768 KiB）**。之后清空长度并不会导致这份容量再次翻倍，新的扩容仍须满足同一条件。[固定工具链的 RawVec 实现](https://github.com/rust-lang/rust/blob/59807616e1fa2540724bfbac14d7976d7e4a3860/library/alloc/src/raw_vec/mod.rs)

## 与已完成页合并

令 A 为 `8191 × size_of::<Value>()`。单代至多出现 96 页，重复哈希按出现次数计费。在途的一页已有文本和此前至多 95 次完整页出现合计至多为 `H = 95 × (A + B) + B`。字节缓冲在读取子值时增长；数组接收子值或收缩时，该次解码调用已返回。两个转换不同时发生。[U 的数组证明](P3_2B1_2U_JSON_ARRAY_GROWTH.md)

| 转换时刻 | 当前页数组 | 解码字节缓冲 | 连同 H 的静态界限 |
| --- | --- | --- | --- |
| 数组增长或收缩 | 3A | 2B | H + 3A + 2B ≤ 49 MiB |
| 解码字节缓冲增长 | 2A | 3B | H + 2A + 3B ≤ 49 MiB |

回归核对键的借用地址、转义键移交时的地址与容量、深层子值返回后的文本，以及重复键和节点限额的首错。自制 256 KiB 夹具使用同一切片解码器和可观察的缓冲检查大文本后继续读取短文本及坏转义。完整解析入口另测页字节上限、长浮点数和错误。第三方解析器私有缓冲的最坏界由上述源码路径推出。[定向回归](../desktop/infrastructure/src/project_format/json/compact_page_tests/text.rs)
