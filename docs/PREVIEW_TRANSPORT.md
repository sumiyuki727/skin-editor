# 自动播放时间轴与精细定位

2026-10-30核对：普通GUI时间轴尚未实现；已有音频内部／诊断的冻结、定位与背景复制锚点，不等于小节定位、真实谱面或统计恢复。以下为预留能力设计v1。适用于皮肤编辑用的自动播放／冻结检查；分数、ACC 和 combo 的跳转后产品呈现策略仍待商讨。参考观察见 [lazer 研究记录](research/LAZER_TIMELINE_20261020.md)，不据此声明 stable 兼容。

## 定位能力

预留绝对歌曲时间、前后小节线、前后拍／细分拍及吸附后的细微时间偏移。拖动时间轴、输入位置及快捷键共用 application 的预览控制用例，不进入项目 Command 或项目历史。

定位请求区分 `AbsoluteTime`、`MusicalGridPosition` 和 `StepGrid`，返回请求位置、解析位置、定位状态与源数据修订。音乐位置由当前谱面的定时段、小节／拍与有理数细分描述解析；不能假定整曲固定 BPM、4/4 或把继承滚速点直接当 BPM。缺少或未验证的定时数据只开放已支持能力，不猜测小节线。

协议使用有界的整数时间单位表达歌曲／谱面时间，并明确二者偏移。小节位置在最终边界统一舍入，避免连续累加漂移。返回音频源实际定位锚点及误差；压缩音频预滚、采样帧取整、渲染帧率与声学延迟分别计量，精细输入不等于已经达到物理采样级精度。

mania 场景的时间定位与判定线空间位置分别建模。跳到小节事件时间不自动证明可见小节线在当前滚速／布局下恰好经过判定线；对应投影和兼容规则须验证。可提供明确标识的静态测试状态帮助调图，不能把注入状态当自然游玩结果。

## 跳转过程

1. 进入定位状态并关闭游戏及自动输入，冻结内容位置；分配新的 TransportEpoch／请求代次。拖动过程中只保留最新候选，取消过期定位。
2. 解析目标，协调音频定位、对象／长物件生命周期、动画相位和场景状态恢复，清除旧 PCM、输入边沿及过期异步结果。不能只修改音乐游标而让对象／判定继续留在旧时间。
3. 对状态恢复结果及新帧核对代次，再原子发布可用状态；失败保持明确的冻结／错误状态，不发布混合的新音频与旧对象。旧画面可暂留但必须带旧来源和 pending 标识，不能继续用它操作新状态。
4. 精细检查默认保持冻结；继续播放走显式控制，或未来带明确策略的“原先播放则恢复”。恢复只能从确认位置开始，不补播被跳过的音效、不补发旧自动输入，也不重放暂停期间墙钟时间。

定位引发的对象／统计状态重建属于专门的预览用例；它与普通暂停后恢复时“禁止追赶”的契约不同。若精确重建需后台模拟历史输入，必须有界、可取消且不输出中间声音／输入，用户明确得到进度和结果来源。

P0 已有音频定位／旧块丢弃的局部实验，但没有完整游戏状态重建。MP3 前缀定位和阻塞 I/O 成本仍是限制，不能继承为即时跳转保证。

### 音效版本与独立试听补充（已采纳，运行时待实现）

[音频编辑方案](AUDIO_EDITING_REVIEW.md)将独立AudioComponent／候选修订与TransportEpoch分开。普通皮肤声音替换／增益编辑不做seek、不重置外部歌曲；freeze／seek才清理对应场景Voice、预排事件及旧样本，恢复不补播。历史检出停止旧皮肤声音，歌曲位置不因项目切头而重置。声音组件不与视觉组件绑定；此段运行时协调仍待实现。

素材库显式试听使用独立位置和试听代次，游戏冻结时不推进Transport；共享设备实现不得简单Reset整流而无意截断试听。Freezing／Frozen确认、设备预提交残余、内容锚点和声学停止分开表达。P2先用fake及自有原生声音验证；长流／循环和真实谱面对应行为仍需各阶段实测，当前占位时钟与端口没有因此增加能力。

## 统计来源必须可辨认，具体模式待定

只改变时间不能推导准确分数／ACC／combo。统计投影预留来源、有效时间段、TransportEpoch、有效性与计算状态；不得把跳转前统计、全曲成绩或自动演示的假定满分静默标成目标时刻的真实累计值。

| 待商讨选项 | 可用性与限制 |
| --- | --- |
| 视觉编辑样例 | 显式使用用户选择的 HUD 样例值或带来源的跳转前快照，编辑器标明“样例／旧快照”；可继续检查数字与 ACC 素材，不冒充当前成绩 |
| 跳转后的区段统计 | 只统计新起点之后，必须显示区段与起点；不能和从头累计结果混用 |
| 从头或可信检查点重建 | 对确定的自动输入重算到目标位置，需验证判定／长物件／combo／统计恢复与性能；完成前保持 pending |

本轮不选定默认呈现模式，也不硬编码“跳转后归零”或“自动 100%”。普通从头播放的真实统计保留独立来源；若暂时无法可靠恢复，状态应明确标未知。HUD 样例通过独立预览设置控制，不修改皮肤配置或真实测试结果。

## 阶段与验收

2026-10-23：[P2背景协调候选](P2_BACKGROUND_COORDINATION.md)已用有限自制PCM接通来源帧定位、暂停确认／重填／恢复及Runtime复制时钟，门闩验证旧确认、冻结回调晚于恢复与皮肤版本无重置。它没有新增时间轴UI、小节解析、真实谱面／统计恢复、未来定时事件或CPAL路径；CopyClock仅是软件输出缓冲锚点，不是设备消费。上述完整产品能力仍按原阶段逐项验收。

P2 可用自有时间轴验证定位请求、冻结后检查与最新请求优先；P4/P5 按玩法接入真实定时／对象／音频。mania 在其玩法阶段补齐长按、滚速变化和判定线投影，不提前宣称支持。

验收覆盖多 BPM／拍号／偏移与定时段边界、前后跳转、冻结状态保持、拖动取消／失败、旧音频／输入／画面拒绝、长物件状态、统计来源以及定位开销。音乐定位能力和统计精确重建能力分别暴露，不能一个按钮存在就把两者都标为支持。
