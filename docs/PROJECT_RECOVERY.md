3. 使用7-Zip打开首卷，按交互提示提供另存的密钥；不要把密钥粘贴进终端命令或脚本参数。解压到新恢复工作区根目录，使包内artifacts相对路径落到原来的对应位置，不覆盖任何尚未审查的已有工程。
4. 读取解密后的artifacts/mania-capability-20261111/recovery/ARTIFACTS-MANIFEST.json，逐项核对路径边界、文件数、长度、SHA-256及修改时间；不能只看7-Zip报告成功或抽查几个文件。冻结程序不因下载而重建，恢复操作不重新运行成本测量。
