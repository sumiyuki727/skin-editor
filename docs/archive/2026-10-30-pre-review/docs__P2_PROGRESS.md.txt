## 实现与依赖

根工作区继续只含domain／application，不增加第三方依赖。`desktop/`拥有独立锁文件；P2-1的五个包在一个进程组装，A1新增仅依赖domain的纯audio库。后续A2已由宿主组装普通GUI的显式音频控制与原生诊断。下表列出原五个包职责及后续基础增量：

| 包 | 实际依赖与职责 |
| --- | --- |
| rendering | domain、wgpu；共享文档／组件计划，CPU 参考与 GPU compute 合成 |
| preview | 无依赖；占位模拟时钟、暂停及输入准入 |
| infrastructure | application、rendering、audio、image、sha2；通用原字节／租约、PNG缓存与音频控制／准备准入 |
| ui | application、egui；视图、工具、参数、草稿与历史调用，定义只绘图的 Presenter |
| host | 上述适配器、eframe、pollster、getrandom；共享 Device／Queue、原生帧租约、导入线程和进程入口 |

两套工作区是构建／检查边界，不是两套服务或跨语言核心，不引入P0依赖。`check_core.py`保持两个纯核心包；`check_desktop.py`现检查六个桌面包与核心依赖、版本、feature、路径及源码，负向用例包括UI／application→audio、audio→infrastructure及纯audio中的I/O。

直接桌面依赖固定 eframe／egui 0.37.0、wgpu 30.0.1、image 0.25.10（仅 PNG）、pollster 1.0.1、sha2 0.10.9、getrandom 0.4.3。图形与初始化组件沿用 P0 评估的版本，正式依赖独立锁定；sha2 用于跨媒体原始字节SHA-256，getrandom 用于历史会话的随机身份。没有模型 SDK、网络服务、WebView 或媒体后端。系统字体与剪贴板由 eframe 的显式 feature 提供；OS 字体只从本机使用，不复制进仓库。直接依赖许可证按本地锁定包元数据均为 MIT／Apache-2.0 双许可；完整传递 notices、字体及安装包仍须在分发前审查，产品许可未定。

## 当前编辑行为

- 启动生成一张自制圆环样例。素材库支持输入 PNG 路径或向窗口投放文件；先导入，再点击“加入当前元素”。不自动扫描目录或读 stable。
- 新建元素、普通图层与嵌套组；选中组后再建组或添加素材可进入该组。支持平移、参数缩放／旋转、透明度／可见性、迁移和删除。
- 跨元素组件可以嵌套并整体变换，成员仍保留独立文档输出边界；像素计划包含成员变换，不只是移动 UI 框。组件合览暂使用明确标注的 512×512 占位工作空间，不代表游戏坐标。
- 画布拖动与连续参数拖动通过 application Begin／Replace／Commit，松开一次提交；Esc、失焦或视口物理尺寸变化取消。无效／失败候选不会替换项目或新建节点。创建新文档并加入首层使用一个原子批次。
- 简单历史祖先列表与后继选择支持撤销、重做、检出和从旧节点继续编辑。暂显示最近 12 个祖先／16 个子分支；完整树浏览仍待完善。
- 独立场景栏、编辑／交互工具、冻结和全屏入口。交互场景只有可点击的占位 GUI、Z/X 输入计数和随模拟时间移动的标记；暂停冻结标记与游戏输入，素材刷新继续。没有谱面、判定、分数、音乐或真正自动打图。
- 用户名／头像、默认皮肤、stable／Songs 来源及自动演示偏好只在设置界面的内存状态中；用户名可作占位展示，其余来源字段预留，不读取／验证或持久化。没有原版设置页或账号网络功能。

变换框和角点为选择辅助，画布当前只支持平移；缩放／旋转通过参数按钮完成，角点拖拽缩放尚未实现。布局可调整侧栏宽度，不提供复杂停靠系统。GUI 判定区与图片边界分开；真实玩法拖动约束、mania 辅助及选择命中映射后续按场景落地。

## 像素与资源契约

直 RGBA8、按 sRGB 解码到线性空间进行 source-over、隔离组透明度、像素中心 nearest 采样、文档画布裁切；CPU／GPU 使用同一个 Plan。这是编辑器的显式基础语义，不宣称是已经验证的 stable 混合／采样规则。PNG 的 ICC／自定义 gamma 不作色彩管理；后续改变须迁移语义并补像素回归。

P2-1新增v1预览值端口，来源含会话、节点／修订、草稿token、目标、模拟时间和视口，返回不透明FrameKey／状态。此端口仍v1，取消token在适配器调用前拒绝。本轮A1另将模型1升级2、Command／Draft4升级5；没有磁盘格式迁移，旧图形证明仍绑定原版本。

NativeHost 复用 eframe 设备，合成完成且来源仍匹配才发布。UI 自己的 Presenter 只接受 FrameKey 和绘制范围，使用 egui-wgpu PaintCallback；不把 Device／TextureId 或 renderer 可变引用传入 UI。待提交绘制持有帧 Arc，完成命令缓冲回调持有最后读取租约，CPU 绘制数据释放且 GPU 回执完成后退休，不猜测延迟帧数。详细约束与待实现部分见[呈现契约](PRESENTATION_CONTRACT.md)。

| 当前限制 | 行为与成本边界 |
| --- | --- |
| 输入 PNG ≤32 MiB；尺寸 ≤4096×4096；单图 RGBA ≤64 MiB | 在后台解码；不合要求明确拒绝 |
| 跨媒体原始字节 ≤128 MiB；RGBA驻留软目标64 MiB、缓存／转换临时副本硬预留80 MiB | A3已允许逐出无人借用的派生像素并从历史固定原字节重建；借用者优先、硬限额仍拒绝。缺页由单候选worker重建，无磁盘存储／LRU；PNG解码器内部成本另计 |
| 导入线程一个；待处理路径四个，暂存结果四个 | 满队列明确背压；活动草稿时延后登记，不能打断项目写通道；不对阻塞文件 I/O 承诺实时取消 |
| 预览目标 ≤1024² 像素；图层组隔离深度 ≤32；合成操作≤65536 | 超限保留模型并诊断，不把 domain 的 10000 层能力冒充渲染深度 |
| 一个合成候选；活动＋退休目标最多八份 | RGBA 目标合计上界约32 MiB，源上传、驱动和其他缓冲另计；旧画面留存并拒绝过期坐标编辑 |
| 一组原图GPU buffer缓存，源数据 ≤80 MiB | A3以弱Raster身份复用参数变更的原图，换源精确暂存并由实际回执保留在途副本；关闭显式清空。后续已由宿主单worker执行解码／打包／GPU提交，GUI维持旧画面；分段与最新验收见[候选准备](P2_FRAME_PREPARATION.md)，不继承P0纹理池成绩 |
| 缩略图40×40，登记最多128个 | 超额不创建新 UI 纹理；分页／驱逐待完善 |

当前 compute 需要相应 storage texture／buffer 能力，缺少适配器明确失败；没有验证自动 CPU fallback。普通呈现不回读 CPU，只有 `--verify-gpu` 诊断执行直接回读。
