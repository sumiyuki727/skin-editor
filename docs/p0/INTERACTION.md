# 可取消拖动与命令会话原型

这是独立 P0 实验，包含一个可拖动的矩形及小型会话拥有者，不是正式 SkinProject、Command 协议或历史树实现。它用于验证 egui 输入经受控命令写入、草稿显示、一次提交和取消的路径；不会固定产品布局，也没有接入旧 stable 或真实游戏逻辑。

## 边界与行为

纯 `interaction.rs` 私有保存已提交节点及可取消草稿。UI 只获得快照值和只读节点列表，通过有类型的 Begin、Move、Commit、Cancel、Checkout 提交请求，不能取得可变文档引用。命令载荷无 UI 控件、闭包或 GPU 对象。该最小原型只操作一个实例的位置，没有素材管理、事务组合、正式历史寻址或资源回收能力。

Begin 检查预期节点并生成会话 token；连续 Move 只刷新草稿，既有节点保持原值。Commit 在内容变化时追加一个节点；无变化、取消或重复提交不新增节点。非法数值和过期 token 不影响当前草稿；已有会话禁止第二个 Begin 或 Checkout。回旧节点后提交保留先前后代，仅用于局部验证分支保留原则。

egui 适配层将屏幕位移转换为视图缩放下的文档位移。释放帧的新位置也参与最后一次更新，不漏掉与按键释放同帧的移动。Esc、失焦、切换工具或改变视图缩放取消草稿，之后的释放不能将其误提交。暂停期间编辑继续刷新，交互工具的游戏点击立即丢弃，恢复时不补跑。

无窗口测试覆盖：300 次草稿更新只提交一次、非法输入回滚、取消与无效操作无节点、过期 token／冲突／忙碌、历史往返与分叉保留；再用真实 egui 控件处理合成 RawInput 验证缩放、释放位置、取消、暂停和输入隔离。它们不需要 GPU 或实际鼠标键盘。

## 原生图像对照

原生 `interaction-proof --self-test` 将合成事件送入与交互模式相同的 egui 控件／命令路径，通过自有渲染器回读四张 PNG：初始、拖动草稿、Esc 取消、第二次拖动提交。检查中央画布草稿变化、取消逐字节恢复、提交变化；整个过程时钟固定为 0、游戏输入为 0，前三阶段仅一个根节点，最后两个节点。

首次原生运行发现测试时序问题：截图回调在 input hook 后推进了脚本，UI 消耗了尚未发送的按下步骤。修正为每步绑定实际送入的输入阶段，增加“回调位于输入与 UI 之间”和同帧重复 UI pass 的无窗口回归，保留失败原始结果。没有放宽图像或历史判定条件。

通过记录和来源见 [windows-interaction.json](windows-interaction.json)。原生回读可以证明该路径在本机绘制了草稿与取消画面，不能证明物理设备输入、操作系统真实焦点转移、中文／日文 IME、高 DPI 切换或全屏返回已经验收。

## 复核与手动体验

```text
python tools/check_p0_interaction.py
python tools/check_p0_interaction.py --run-native
experiments/p0-egui/target/release/interaction-proof.exe --interactive
```

第一项运行无窗口测试、依赖与纯模块边界检查、格式、Clippy 和构建。第二项额外启动隐藏的自有原生窗口，读取渲染结果并退出，检查路径边界与已有输出保护。交互模式是同一已构建入口，尚未人工验收；启动后拖动蓝色矩形，Esc 取消，松开提交，点击旧 Node 再拖动可观察分叉保留。

没有新增依赖、常驻服务、系统输入注入或系统窗口捕获。实现仅位于 experiments，未建立产品核心；正式 P1 仍需事务、资源跨分支引用和完整结构化接口测试。

后续[连续编辑扩展](EDIT_COMPOSITION.md)已经将此输入／会话路径接入 50 层文档的 GPU 合成与直接呈现，并另行重复测量。本文中的矩形回读仍保留原口径，不将它改写为当时已验证完整合成。

音频预检查只调用 `winmm.waveOutGetNumDevs`，本机返回 5 个 Wave 输出入口；可能包含虚拟设备，未打开设备、播放或测量延迟，不能作为真实音频验收。WMI 设备信息查询被系统拒绝，未据此推断设备缺失。[微软将 Waveform Audio 列为旧 API](https://learn.microsoft.com/en-us/windows/win32/multimedia/waveform-functions)，此次仅用于只读发现，不选为产品音频后端。真实播放／暂停时钟及低延迟跨平台后端仍是下一项 P0 验证。

随后独立 [WASAPI 诊断](AUDIO_DEVICE.md)已经打开静音输出流并验证设备位置的暂停／恢复；可听声音、模拟／输入联动和低延迟跨平台后端仍未验收。
