# 历史实验与保留索引

这里的四个P0工作区属于历史实验，不是产品架构的一部分。产品实际图只含根domain／application和desktop六包，禁止反向依赖这些实验。

| 工作区 | 保留用途 |
| --- | --- |
| p0-preview-contract | 初始暂停／刷新／输入契约证据 |
| p0-egui | 原生GUI／GPU／上传／故障及独立音频组合实验 |
| p0-media | 自制WAV／MP3／Ogg、有限流／定位和参考fixture；产品当前未接压缩音频 |
| p0-wasapi | 初期Windows输出／格式／端点实验，不是当前CPAL产品后端 |

各自README和工具仍引用原路径，Cargo根exclude及负向回归也依赖这些边界，因此本轮只标记历史保留，不移动或删除源码、锁文件、自制fixture。它们不能作为产品运行／测试依赖，也不因未来可能参考就自动获准复用其依赖或实测结论。

清理缓存、移走证据或拆分宿主诊断须另做引用和重现审查；本轮只归档失效的文档叙述，见[审阅包](../docs/review/README.md)。
